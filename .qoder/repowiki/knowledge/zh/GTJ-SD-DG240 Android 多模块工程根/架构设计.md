通过 settings.gradle 声明 include ':app' 与 ':utillibrary' 构成双模块结构；根 build.gradle 以插件管理方式集中声明 Android Gradle Plugin 8.8.2 与 GreenDAO 3.3.1 插件版本，避免子模块各自维护版本；gradle.properties 在全局启用 AndroidX、Jetifier、并行构建、构建缓存与按需配置，并指定 Java 17 (Corretto) 作为 AGP 运行环境；仓库源在 pluginManagement 与 dependencyResolutionManagement 中统一配置阿里云镜像与 JitPack，并通过 repositoriesMode.FAIL_ON_PROJECT_REPOS 强制子模块不得自行声明仓库，确保依赖来源一致。app 模块依赖 utillibrary 提供的 MVP 基类、日志、USB OTG、图片代理等能力，形成「应用层 + 基础库」的单向依赖关系。
