本模块是一个 Android Library（`com.android.library`），通过 `build.gradle` 声明 `compileSdk 35 / minSdk 24`，对外暴露 `com.blackhao.utillibrary.*` 包下的工具与基类。
- 分层组织：按功能划分为 `base`（CommonBaseAdapter、LoadingDialog）、`mvp`（Activity/Fragment/Presenter/View 抽象基类与 BlankContract）、`log`（LogHelper 单例日志）、`file`（FileUtil 文件操作）、`time`（TimeUtil）、`regular`（RegularUtil）、`imgProxy`（ImgDisplayUtil + ImgProxyImpl 接口实现解耦）、`usbHelper`（UsbHelper + USBBroadCastReceiver 封装 libaums 的 OTG 读写）。
- 依赖方向：各子模块相互独立，仅 `mvp` 依赖 `base` 和 `log`；`imgProxy`、`usbHelper`、`file` 等工具类不反向依赖 UI 层，保证可被任意 Activity/Fragment 复用。
- 扩展点：`imgproxy` 通过 `ImgProxyImpl` 接口 + `ImgDisplayUtil` 单例代理，允许上层注入具体图片加载实现；`mvp` 通过 `BaseMvpActivity/BaseMvpFragment` 暴露 `initUI/initData/initListener/handleMessage` 等抽象方法，统一生命周期与弱引用 Handler 机制。
- 资源：`res/drawable`、`res/layout`、`res/values` 提供 LoadingDialog 所需的布局与颜色字符串，由库自身管理。
- 外部依赖：仅 `androidx.appcompat` 与 `com.github.mjdev:libaums:0.7.4`（USB 存储），其余均为 Android SDK 原生 API。
