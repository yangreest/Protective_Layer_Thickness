- 工具类普遍采用双重检查锁定的 volatile 单例模式（如 LogHelper、ImgDisplayUtil），并通过 getInstance() 获取实例。
- 持有 Context 或 View 的类一律使用 WeakReference 包装，避免内存泄漏（BaseMvpPresenterImpl、CommonBaseAdapter、UsbHelper）。
- MVP 基类通过抽象方法暴露扩展点（initUI/initData/initListener/handleMessage/getLayoutResId/bindView/initData），子类只需实现业务逻辑。
- 跨线程 UI 操作统一通过内部 WeakHandler.post 回主线程执行（showToast/showLoading/dismissLoading 等方法均先 isUIThread 判断再 post）。
- 对外部实现的替换通过接口 + 单例代理完成（ImgProxyImpl 接口由 ImgDisplayUtil 代理，init 时注入具体实现）。
- 日志输出统一经 LogHelper，并按 BuildConfig.DEBUG 与 LOG_LEVEL 控制是否打印，同时支持 JSON 格式化与可选文件落盘。
